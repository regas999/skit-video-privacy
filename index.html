Skit Video Uploader

Skit Video Uploader is a private publishing tool used by the creator of the YouTube channels Prompt Panik (Turkish) and Vibe & Bug (English). These channels publish short animated skits about AI tools and news.

The tool uploads the creator's own videos to the creator's own channels. It is not offered to the public and does not access anyone else's account.

YouTube API Services

This tool uses YouTube API Services (YouTube Data API v3) to upload videos to the creator's own YouTube channels. By using it, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at Google Account → Third-party access.

It also publishes the same videos to the creator's own Instagram and TikTok accounts.
